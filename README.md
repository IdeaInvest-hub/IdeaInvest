# IdeaInvest V3 — Web-first platform prototype

**Brand:** IdeaInvest  
**Tagline:** Fueling Innovation

## Features
- Investor, Innovator, Admin and Industrial Partner role preview
- Overview dashboard and opportunity marketplace
- Project details and local demo interest/watchlist
- Idea submission form
- Admin review queue and status changes
- Responsive desktop/mobile layout
- Browser-local persistence via `localStorage`

## Run locally
Extract the ZIP and open `index.html` in a modern browser.

## Publish using GitHub Pages
1. Sign in at https://github.com and create a repository named `ideainvest-v3`.
2. Upload `index.html` and `README.md` from this folder.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Follow the published URL shown in the Pages settings.

## Production limitations
This is a front-end prototype only. It has no real authentication, central database, document uploads, payment processing, escrow, identity verification, secure admin permissions or audit trail. Data is stored only in the current browser and is not shared across users/devices. Do not collect sensitive/confidential information. Before real investment activity, obtain specialist legal/regulatory advice and implement appropriate licensing, KYC/AML, privacy, cybersecurity and investor-protection controls.
