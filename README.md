# IdeaInvest Website Prototype

Brand: IdeaInvest
Tagline: Fueling Innovation

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Create a GitHub repository named `ideainvest`, upload `index.html`, then enable Pages from Settings > Pages using the `main` branch and root folder.

## Important
This is a front-end prototype. It does not process investments, payments, KYC/AML, investor onboarding, or store idea submissions.
